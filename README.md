# C++ Projects Repository

This repository contains various C++ projects organized into separate folders. Each project serves a different purpose, including encryption, algorithms, graphical user interfaces, and more.

## 📂 Folder Structure

- **Encryption** - Contains implementations of cryptographic algorithms and security-related projects.
- **FCAI_Tasks** - Assignments and projects related to Faculty of Computer and Artificial Intelligence (FCAI).
- **Games** - Game development projects in C++.
- **General Projects** - Miscellaneous C++ projects that do not fit into other categories.
- **GUI** - C++ projects involving Graphical User Interfaces.
- **HUFFMAN_Algorithm** - Implementation of Huffman Encoding for data compression.
- **Photoshop** - Image processing projects inspired by Photoshop functionalities.
- **VOLE_machine** - A project related to VOLE (Vector Oblivious Linear Evaluation) or machine learning concepts.

## 🛠 Technologies Used
- C++ Standard Library (STL)
- OpenGL (for graphics, if applicable)
- Qt or wxWidgets (for GUI-based applications)
- Cryptographic Libraries (if used in encryption projects)

## 🚀 How to Run a Project
1. Navigate to the desired project folder.
2. Open the `.cpp` files in a C++ IDE such as **VS Code, CLion, or Code::Blocks**.
3. Compile the project using:
   g++ -o output main.cpp
   ./output
